# Licence Scope and Data Availability

The existing MIT licence is retained for repository source code and software
documentation. No new ownership or blanket redistribution claim is made for
ESM-derived observations, third-party site data, agency earthquake catalogues,
or other underlying geospatial products. Refer to their original terms.

The retained ESM training table and source workbook are not uploaded. Nor are
record-level ESM validation predictions, raw SHAP rows, source-event coordinate
inventories or original caret objects containing training observations.

Published inference model objects contain learned model parameters and fitted
preprocessing summaries, not the training records. Their distribution is not
a grant to redistribute the underlying ESM database. Static site grids and
scenario results are supplied as research materials with their provenance;
their inclusion does not relicense third-party source products under MIT.

No new Zenodo record or DOI is created by this repository update.
